# BMI Calculator

A simple Python project to calculate Body Mass Index (BMI) based on user input for weight and height. The script also classifies the BMI result.

## How it Works

- Prompts the user for name, weight (in pounds), and height (in inches).
- Calculates BMI using the formula:  
  BMI = (weight * 703) / (height * height)
- Prints the BMI value and a weight category message.

## Skills Demonstrated

- User input handling in Python
- Mathematical calculations
- Conditional logic

## Usage

1. Run the script.
2. Enter your name, weight, and height when prompted.
